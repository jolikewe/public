TikTok Campaign Username Extractor

Paste the leaderboard data you copied from your browser's Network tab. It pulls out every display name and @username (linked to their TikTok profile), sorted by score. Runs entirely in your browser — it only reads what you give it and never contacts TikTok.

How to get the data to paste
  1. Open the campaign page while logged in, press F12, open the Network tab, filter by Fetch/XHR.
  2. Click through each tab (Star Legend, Rising Star, Star Seeker). Scroll each to the bottom so every "load more" request fires.
  3. For each request that returns rankings: right-click → Copy → Copy response, paste below. Stack all three tabs' responses in the box — they're all read and combined into one list.
  4. Or right-click the Network list → Save all as HAR, open the file, paste its contents here. HAR is detected automatically.
